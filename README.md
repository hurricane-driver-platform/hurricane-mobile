# Hurricane Express - Driver Mobile App

A cross-platform mobile application built for Hurricane Express over-the-road truck drivers to foster community, track performance metrics, and redeem rewards. Built as a 2026 Capstone Project.

## 🚀 Tech Stack
- **Frontend:** React Native, Expo, TypeScript
- **State Management:** Zustand
- **Backend & Auth:** Supabase (PostgreSQL)
- **Data Caching:** TanStack Query

## ✨ Key Features
- **Performance Tracking:** Real-time visibility into miles driven, fuel efficiency, and safety compliance.
- **Leaderboards & Competitions:** Filterable rankings by truck type and performance area.
- **Rewards Store:** Redeem earned performance points for company merchandise.
- **Community Forums:** Message boards for drivers to connect, post, and upvote content.

## 🛠️ Local Development Setup
1. Clone the repository: `git clone https://github.com/YourOrgName/hurricane-mobile.git`
2. Install dependencies: `npm install`
3. Set up environment variables: Create a `.env` file and add your `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
4. Start the Expo development server: `npx expo start`
5. Scan the QR code with the Expo Go app on your physical iOS or Android device.
